Part 2: Privacy Policy & Data Disclosures

1. Cloud Synchronization & Google Drive API Disclosures

Ghostway offers optional cloud synchronization features to backup and restore serialized database state files using Google Identity services (chrome.identity) and the Google Drive REST API.

  • Scoped Access Limits: Ghostway requests access exclusively to the Google Drive Application Data folder (drive.appdata).
  • Data Isolation: Ghostway cannot view, read, modify, or delete any personal files, documents, or photos in your main Google Drive directory.
  • Use of OAuth Data: Authentication tokens and database files transferred to/from Google Drive are used strictly for local state rehydration and cloud backup restoration. They are never transmitted to third-party analytics platforms or sold to data brokers.

2. Local Storage and Processing

Ghostway stores domain rules, cached transaction statuses, and local application states on your device using chrome.storage.local. Local data persists until cleared by the user or upon extension reinstallation.

3. Google API Limited Use Compliance

Ghostway’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Children’s Privacy (COPPA & GDPR Compliance)

Ghostway is not directed toward children under 13 years of age (or under 16 in the European Union). We do not knowingly collect personal information from children.

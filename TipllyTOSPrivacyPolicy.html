2. Description of Service

Tiplly is an open, client-side browser extension designed to detect public cryptocurrency wallet addresses on supported web pages (including YouTube content descriptions and custom web attributes) and provide an interface for peer-to-peer cryptocurrency micro-tipping.

3. Non-Custodial & Direct Wallet Intermediary

  • No Custody of Funds: Tiplly is strictly a client-side interface tool. Tiplly does not hold, store, manage, receive, process, or transmit user funds, private keys, or seed phrases.

  • Network Fees: You are solely responsible for reviewing and confirming transaction details, recipient public addresses, and network execution fees (gas fees) prior to signing any transaction via your wallet.

Part 2: Privacy Policy

1. Information Collection and Storage

  • Local Processing: Address detection and UI components operate locally within your browser runtime environment.
  • Local Storage (chrome.storage.local): Tiplly stores user configuration preferences, active network selections, and cached local records exclusively using the browser's local storage API (chrome.storage.local / LokiJS). This data remains on your local device.
  • No Telemetry or Tracking: Tiplly does not track your cross-site browsing history, profile user behavior across external domains, or collect personally identifiable information (PII).

2. Third-Party Web Interactions & RPC Nodes

When broadcasting or estimating transactions, Tiplly communicates with public RPC (Remote Procedure Call) endpoints or blockchain nodes to fetch gas prices, address balances, or transaction statuses. These requests convey only necessary public metadata (such as public wallet addresses and transaction payload parameters) required to complete the action.
